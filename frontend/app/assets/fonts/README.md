# Inter Font Files

This directory contains the Inter font files for the Vaani app with multiple point size variants.

## Installed Font Families:

### Inter (24pt) - Primary Body Text
- `Inter_24pt-Regular.ttf` (weight: 400)
- `Inter_24pt-Medium.ttf` (weight: 500) 
- `Inter_24pt-SemiBold.ttf` (weight: 600)
- `Inter_24pt-Bold.ttf` (weight: 700)
- Plus italic variants for all weights

### InterDisplay (28pt) - Large Headings & Display Text
- `Inter_28pt-Regular.ttf` (weight: 400)
- `Inter_28pt-Medium.ttf` (weight: 500)
- `Inter_28pt-SemiBold.ttf` (weight: 600)
- `Inter_28pt-Bold.ttf` (weight: 700)

### InterText (18pt) - Small Text & Labels
- `Inter_18pt-Regular.ttf` (weight: 400)
- `Inter_18pt-Medium.ttf` (weight: 500)
- `Inter_18pt-SemiBold.ttf` (weight: 600)
- `Inter_18pt-Bold.ttf` (weight: 700)

## Font Usage in App:

- **InterDisplay**: Used for display text, large headings (displayLarge, displayMedium, displaySmall, headlineLarge, headlineMedium)
- **Inter**: Used for main body text, titles, and most UI elements (headlineSmall, titleLarge, titleMedium, bodyLarge, bodyMedium)
- **InterText**: Used for small text like labels, captions, and navigation (titleSmall, bodySmall, labelLarge, labelMedium, labelSmall)

## Typography Hierarchy:
This multi-point-size system provides:
- Better text rendering at different sizes
- Optimized readability for each text level
- Professional typography scaling
- Consistent visual hierarchy
